# 02 · 配置说明

> 本文解释「每个配置文件是干什么的、哪些字段必须改、改了之后怎么生效」。
> 真实配置由 `deploy\install.ps1` 从 `templates\` 渲染，**不要直接改仓库里的模板来跑机器人**。

---

## 1. 配置文件地图

```text
deploy\config.psd1                     本机部署参数（QQ、Key、令牌、路径）★ 含密钥
templates\astrbot\cmd_config.json      AstrBot 主配置模板
templates\astrbot\plugins\*.json       10 个插件配置模板
templates\snowluma\*.json              SnowLuma 配置模板
        │
        │  install.ps1 + render_config.py 渲染
        ▼
astrbot\data\cmd_config.json           AstrBot 主配置（运行时）★ 含密钥
astrbot\data\config\*.json             插件配置（运行时，可能含 Cookie）★
C:\SnowLuma\config\onebot.json         OneBot 全局网络 ★ 含令牌
C:\SnowLuma\config\onebot_<QQ>.json    账号级覆盖 ★ 含令牌
C:\SnowLuma\config\runtime.json        WebUI 端口 / hook 自动加载
C:\SnowLuma\config\webui.json          WebUI 密码哈希
```

★ 的文件都在 `.gitignore` 里，**永远不要提交**。

### 1.1 占位符

模板里只有四种占位符，`render_config.py` 会替换：

| 占位符 | 替换为 |
|---|---|
| `sk-REPLACE_WITH_YOUR_DEEPSEEK_KEY` | `deploy\config.psd1` 的 `DeepSeekKey`（空则留空数组） |
| `YOUR_QQ_NUMBER` | `AdminQQ`（主人 QQ） |
| `snowluma:FriendMessage:YOUR_QQ_NUMBER` | `snowluma:FriendMessage:<AdminQQ>` |
| `REPLACE_WITH_RANDOM_ONEBOT_TOKEN` | 随机 32 位十六进制令牌 |

`install.ps1` 重复运行是幂等的：已存在的运行时配置默认**不覆盖**（加 `-Force` 才覆盖）。

## 2. `deploy\config.psd1`（本机参数）

```powershell
@{
    BotQQ        = '123456789'
    AdminQQ      = '100000001'
    OneBotToken  = '................................'
    DeepSeekKey  = 'sk-................................'

    AstrBotHome  = 'astrbot'            # 相对仓库根，也可以写绝对路径
    SnowLumaHome = 'C:\SnowLuma'
    QQExe        = 'C:\Program Files\Tencent\QQNT\QQ.exe'
    LogsDir      = 'logs'
    ToolsBin     = ''                   # ffmpeg/yt-dlp 所在目录，可选

    SnowLumaWebUIPassword = 'SnowLuma@xxxxxxxx'

    EmbeddingEnabled  = $true
    EmbeddingPython   = ''
    EmbeddingModelDir = 'models\bge-small-zh-v1.5'

    TtsEnabled   = $false
    TtsExe       = ''
    TtsModelDir  = 'models\tts\kurisu-v2proplus'
    TtsSharedDir = ''
    TtsPort      = 9882
}
```

| 字段 | 说明 |
|---|---|
| `BotQQ` | 机器人小号，SnowLuma 账号级配置文件名用得到 |
| `AdminQQ` | 写进 `admins_id`，并作为主动消息/通知的默认接收人 |
| `OneBotToken` | 两端共享令牌；改了必须同时改 `cmd_config.json` 和 SnowLuma |
| `DeepSeekKey` | 对话模型 Key；也可登录 WebUI 再填 |
| `AstrBotHome` | AstrBot 工作目录，里面必须有 `.astrbot` 和 `data\` |
| `SnowLumaHome` | SnowLuma 解压目录，里面必须有 `node.exe` |
| `QQExe` | `start-all.ps1` 最后一步拉起 QQ 用；留空则自动探测 |
| `ToolsBin` | 把 ffmpeg / ffprobe / yt-dlp 放进 PATH（B 站插件视频解析要用） |
| `EmbeddingEnabled` | `false` 时 `start-all` 跳过向量服务 |
| `EmbeddingPython` | 留空 = 仓库下 `.venv-embedding\Scripts\python.exe` |
| `TtsEnabled` | 本地日语语音开关 |
| `TtsExe` | `aniflive-tts.exe` 路径 |
| `TtsSharedDir` | AnifLive 的 shared 目录，留空 = 模型目录上一级的 `shared` |

改完不需要重装，重启对应服务即可（`start-*.ps1` 每次都会重新读这个文件）。

## 3. AstrBot 主配置 `astrbot\data\cmd_config.json`

### 3.1 结构总览

| 段 | 作用 |
|---|---|
| `platform` | 接入的平台（这里只有 `snowluma`，类型 `aiocqhttp`） |
| `provider_sources` | 模型来源（DeepSeek API、本地向量服务） |
| `provider` | 具体模型条目（`deepseek/deepseek-flash` 等） |
| `provider_settings` | 全局模型策略（默认模型、联网搜索、工具、沙箱） |
| `agent_runner` | Agent 运行参数（模型、人格、压缩、最大步数） |
| `provider_tts_settings` / `provider_stt_settings` | AstrBot 自带 TTS/STT（本项目 TTS 关、STT 空） |
| `dashboard` | WebUI 监听、用户名、密码哈希、JWT |
| `admins_id` | 管理员 ID 列表 |
| `wake_prefix` | 群里唤醒前缀 |
| `kb_names` | 知识库名称列表 |
| `plugin_set` | 启用的插件（`["*"]` = 全部） |

### 3.2 必须关注的字段

```json
"platform": [{
  "id": "snowluma",
  "type": "aiocqhttp",
  "enable": true,
  "ws_reverse_host": "127.0.0.1",
  "ws_reverse_port": 6199,
  "ws_reverse_token": "<与 SnowLuma 一致>"
}]
```

| 字段 | 说明 |
|---|---|
| `ws_reverse_host/port` | AstrBot 作为 WS 服务端的监听地址；保持 `127.0.0.1:6199` |
| `ws_reverse_token` | 必须等于 SnowLuma 的 `accessToken` |
| `enable` | `false` 会导致平台不加载 |

```json
"provider_sources": [
  { "provider": "deepseek", "id": "deepseek", "key": ["sk-..."], "api_base": "https://api.deepseek.com/v1" },
  { "provider": "openai", "id": "local_bge", "type": "openai_embedding",
    "embedding_api_base": "http://127.0.0.1:8010/v1", "embedding_api_key": "sk-local",
    "embedding_model": "bge-small-zh-v1.5", "embedding_dimensions": 512 }
]
```

- `deepseek.key` 是**数组**，可以放多个 Key 轮询。
- **仓库不提供 Key**：每个部署者填自己的 DeepSeek Key，费用记在自己账户；留空则机器人不会回话。
- `local_bge` 的 Key 随便填（本地服务不校验），但 `embedding_dimensions` 必须是 **512**（bge-small-zh-v1.5 的维度）。

```json
"admins_id": ["astrbot", "100000001"]
```

- `astrbot` 是面板用户名，保留。
- 第二个是主人 QQ，`/bili主动`、`/bili登录` 等命令要求管理员。
- **不要**把机器人自己的 QQ 加进来（它不需要管理员权限）。

```json
"agent_runner": {
  "config": {
    "model": { "provider_id": "deepseek/deepseek-flash" },
    "persona": { "persona_id": "牧濑红莉牺", "safety_mode": true }
  }
}
```

- 改默认模型改这里；改默认人格也可以改这里（或 WebUI 里点「设为默认」）。
- `safety_mode: system_prompt` 表示用系统提示词做安全约束。

```json
"provider_tts_settings": { "enable": false, "provider_id": "aniflive_tts" },
"provider_stt_settings": { "enable": true, "provider_id": "" }
```

- TTS 保持 `false`：语音由 `ja_voice` 插件接管，两者同时开会重复发语音。
- STT 的 `provider_id` 为空 = 听不懂语音消息。

### 3.3 `dashboard`

```json
"dashboard": {
  "username": "astrbot",
  "password": "",
  "pbkdf2_password": "",
  "jwt_secret": "",
  "password_change_required": true,
  "host": "127.0.0.1",
  "port": 6185
}
```

三个空值是有意为之：AstrBot 首次启动发现密码为空，会**随机生成一个强密码并打印到控制台/日志**，同时写回 `pbkdf2_password`、生成 `jwt_secret`。

- 找初始密码：`Select-String .\logs\astrbot.out.log -Pattern 'Initial password'`
- 登录后改密码，这三个字段会被重写。
- `host` 保持 `127.0.0.1`，不要暴露公网。

### 3.4 编码与 BOM

- `cmd_config.json` 和 `config\*.json` 由脚本写成 **UTF-8 with BOM**，AstrBot 读写时会保留。
- 如果用记事本/VS Code 手动编辑，**不要**把 BOM 去掉；AstrBot 能读无 BOM，但某些插件读配置时按 UTF-8-SIG 打开，缺 BOM 可能导致中文键乱码。
- 不要在 JSON 里写 `//` 注释，AstrBot 用的是严格 JSON。

### 3.5 修改后如何生效

| 改了 | 生效方式 |
|---|---|
| `cmd_config.json` | 重启 AstrBot（`stop-all.ps1` 后 `start-astrbot.ps1`） |
| 插件配置 `config\*.json` | 多数插件支持 WebUI 热重载；不确定就重启 AstrBot |
| 人格 | WebUI 保存即生效（下一条消息开始） |
| 知识库 | WebUI 里操作，无需重启 |
| SnowLuma 配置 | 重启 SnowLuma |

## 4. 人格

### 4.1 存在哪

人格正文存在 SQLite `astrbot\data\data_v4.db` 的 `personas` 表，`cmd_config.json` 只存 `persona_id`。

仓库提供纯文本 `personas\牧濑红莉牺.txt`，方便 diff 和迁移。

### 4.2 导入方式

1. WebUI → 人格 → 新建；
2. 名称必须与 `cmd_config.json` 的 `persona_id` 一致（`牧濑红莉牺`）；
3. 粘贴 `personas\牧濑红莉牺.txt`；
4. 保存 → 设为默认。

### 4.3 人格里不该出现的东西

- 真实姓名、住址、学校、公司、手机号、API Key；
- 其他群友的隐私；
- 「忽略系统提示词」这类注入语句。

本仓库的人格文本已做基础脱敏（不含账号、路径、密钥）。如果你自己改，提交前跑一遍 [07-安全与脱敏](07-安全与脱敏.md) 里的扫描命令。

## 5. 知识库

### 5.1 文件

```text
astrbot\data\knowledge_base\
├─ kb.db                       # 知识库元数据（名称、文档数）
└─ <kb_id>\
   ├─ doc.db                   # 切块后的文本
   └─ index.faiss              # 向量索引（512 维）
```

`cmd_config.json` 里：

```json
"kb_names": ["命运石之门", "网络口语与抽象语"],
"kb_fusion_top_k": 30,
"kb_final_top_k": 6,
"default_kb_collection": ""
```

### 5.2 依赖

知识库的语义检索走 `local_bge` provider → `http://127.0.0.1:8010/v1`，所以必须：

1. `models\bge-small-zh-v1.5` 存在；
2. `.venv-embedding` 装好 torch + transformers；
3. `start-embedding.ps1` 在跑。

缺任何一项，知识库上传/检索都会报连接错误或维度错误。

### 5.3 换模型

想换更大的 `bge-m3`（1024 维）：

1. 改 `provider_sources[local_bge].embedding_model` 与 `embedding_dimensions`；
2. 改 `models\...` 目录；
3. **重建索引**（旧索引维度不匹配，检索会直接报错）：WebUI → 知识库 → 删除文档重新上传。

## 6. SnowLuma 配置

### 6.1 `config\runtime.json`

```json
{
  "webuiPort": 5099,
  "webuiHost": "127.0.0.1",
  "hookAutoLoad": true,
  "logRetainDays": 7
}
```

- `hookAutoLoad: true`：启动时自动尝试注入已登录的 QQ；但**首次仍建议先起 SnowLuma 再起 QQ**。
- 端口冲突时改 `webuiPort`，同时改 `deploy\open-admin.ps1` 里的地址。

### 6.2 `config\onebot.json`（全局默认）

| 网络 | 说明 |
|---|---|
| `httpServers` | OneBot HTTP API，`127.0.0.1:3000` |
| `wsServers` | OneBot 正向 WS 服务端，`127.0.0.1:3001` |
| `wsClients` | **反向 WS 客户端**，连 AstrBot 的 `ws://127.0.0.1:6199/ws` |
| `httpClients` | 无 |

AstrBot 只需要 `wsClients` 这一条；`accessToken` 必须与 AstrBot 的 `ws_reverse_token` 一致。

### 6.3 `config\onebot_<QQ>.json`（账号级）

登录后 SnowLuma 为每个 QQ 生成一份，字段覆盖全局同名网络。注意：

- 机器人账号：`wsClients[astrbot].enabled = true`
- 其他账号：`wsClients[astrbot].enabled = false`（否则重复回复）
- 账号级文件里的 `accessToken` 可能被 WebUI 重写，改完在 AstrBot 里同步改。

### 6.4 `config\webui.json`

密码哈希，不要手改。忘记密码：停 SnowLuma → 删除（或改名）`webui.json` → 启动时用 `SNOWLUMA_WEBUI_BOOTSTRAP_PASSWORD` 重新初始化。

## 7. 端口与 UMO

### 7.1 端口

见 [README 端口表](../README.md#端口一览)。全部只监听回环。

### 7.2 UMO 格式

```text
<平台ID>:<消息类型>:<会话ID>
snowluma:FriendMessage:100000001      # 私聊
snowluma:GroupMessage:123456789       # 群聊
```

插件里凡是「会话列表 / 通知目标 / 管理端触发」都要求这个格式。`install.ps1` 会把模板里的 `YOUR_QQ_NUMBER` 换成你的主人 QQ。

## 8. 常见配置错误

| 错误 | 后果 | 修正 |
|---|---|---|
| 两端令牌不一致 | SnowLuma 一直重连，AstrBot 无消息 | 统一 `OneBotToken` |
| `admins_id` 没加主人 QQ | `/bili主动` 提示无权限 | 加进数组 |
| `embedding_dimensions` 写 1024 但用 bge-small | 检索报维度错误 | 改回 512 或换模型 |
| 两个账号都开了 `wsClients` | 重复回复 | 只留机器人账号 |
| `provider_tts_settings.enable = true` 同时开 `ja_voice` | 重复语音 | 保持 AstrBot 自带 TTS 为 `false` |
| `cmd_config.json` 少 BOM 且含中文 | 插件配置读取乱码 | 用脚本重新渲染，或存为 UTF-8 BOM |
