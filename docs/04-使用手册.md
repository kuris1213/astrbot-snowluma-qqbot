# 04 · 使用手册

> 面向「已经部署好，日常怎么用」。部署见 [01](01-部署指南.md)，配置字段见 [02](02-配置说明.md)。

---

## 1. 日常开关机

```powershell
# 启动整套（向量 → SnowLuma → AstrBot → TTS → QQ）
.\deploy\start-all.ps1

# 只起服务，不动 QQ
.\deploy\start-all.ps1 -NoQQ

# 停止（保留 QQ）
.\deploy\stop-all.ps1

# 连 QQ 一起关
.\deploy\stop-all.ps1 -IncludeQQ
```

双击仓库根目录的 **`打开管理页.bat`**：服务没起会先在后台拉起，然后依次打开 AstrBot / SnowLuma / 主动消息三个页面。

### 只想重启某一个

```powershell
.\deploy\stop-all.ps1          # 或只在任务管理器结束对应 PID
.\deploy\start-astrbot.ps1     # 只起 AstrBot
```

`start-*.ps1` 都是幂等的：端口已在监听就跳过，不会起两份。

### 什么时候必须重启 QQ

- 机器人「能发消息、但收不到别人发的消息」→ 停 SnowLuma → 重启 QQ → 再起 SnowLuma；
- 换了机器人账号；
- QQ 自动更新之后（hook 可能失效）。

| 页面 | 地址 | 能干什么 |
|---|---|---|
| AstrBot | <http://127.0.0.1:6185> | 平台、模型、人格、知识库、插件、会话、日志 |
| SnowLuma | <http://127.0.0.1:5099> | 账号、OneBot 网络、hook 状态、协议端日志 |

## 3. 怎么跟机器人说话

### 私聊

直接发，不需要前缀。机器人会按默认人格回复。

### 群聊

默认唤醒前缀是 `/`，另外 @ 机器人也会唤醒：

```text
/在吗
@牧濑红莉牺 今天吃什么
```

不想每条都加 `/`：AstrBot → 配置 → 平台设置 → 唤醒前缀，或改 `cmd_config.json` 的 `wake_prefix`。

### 会话标识（UMO）

插件配置里填「会话」时用这个格式：

```text
snowluma:FriendMessage:100000001      # 和主人私聊
snowluma:GroupMessage:123456789       # 某个群
```

## 5. 主动消息

### 触发逻辑

私聊冷场 `auto_trigger_after_minutes`（默认 60 分钟）后，按 `min/max_interval_minutes`（30~120 分钟随机）主动开口；`quiet_hours`（23~10 点）不打扰；连续 4 次没回就暂停，你回一句自动重置。

### 改频率

`astrbot\data\config\astrbot_plugin_proactive_chat_config.json`：

```json
"schedule_settings": {
  "min_interval_minutes": 30,
  "max_interval_minutes": 120,
  "quiet_hours": "23-10",
  "max_unanswered_times": 4
}
```

改完重启 AstrBot。

### 暂停 / 恢复

```json
"friend_settings": { "enable": false }
```

或者 `friend_settings.session_list` 改成 `[]`（空 = 永不触发）。

### 手动触发一次

```powershell
$umo = [uri]::EscapeDataString('snowluma:FriendMessage:<主人QQ>')
Invoke-WebRequest "http://127.0.0.1:4100/api/jobs/$umo/trigger" -Method Post `
  -Body '{}' -ContentType 'application/json' -UseBasicParsing
```

会**真的发消息**，测试时注意。

## 6. 表情包

### 机制

插件把分类表注入提示词，模型想配图时输出 `&&happy&&` 这样的标记，插件删掉标记并从对应分类随机抽一张图发出去。所以：

- 模型不会「看到」图片内容，只会选分类；
- 分类描述写得越清楚，配图越准；
- 没有合适分类时应该只回文字。

### 换包 / 加包

AstrBot → 插件 → 表情包管理器：

- 查看图库、导入资源包、设为默认包；
- 恢复默认表情包；
- 打开/关闭自动收集。

仓库自带两套：`deepseek-girl-pack`（大肥鱼，45 张）、`local-9552ab28ba5fe56b`（牧濑红莉牺，135 张，默认）。

### 自动收集

群友发的图有 50% 概率被识别、打标、入库（默认不人工审核）。不想收：

```json
"auto_collect": { "enabled": false }
```

`plugin_data\meme_manager\` 会越用越大，定期清理 `packs\` 里不要的包。

## 7. B 站

### 首次使用

1. 配好 `DEDE_USER_ID`（机器人 B 站 UID）、`OWNER_MID`（主人 B 站 UID）；
2. 在 AstrBot 插件配置里填 Cookie（或扫码）；
3. 私聊机器人发 `/bili登录` 走登录流程；
4. `/bili状态` 确认在线。

### 日常

- **回评论**：`ENABLE_REPLY = true`，20 秒轮询一次，按兴趣过滤；
- **回私信**：默认只回主人（`PRIVATE_MESSAGE_REPLY_SCOPE = owner`）；
- **主动看视频**：`ENABLE_PROACTIVE = true`，每天最多 4 次，按分数点赞/收藏/关注/评论；
- **推送给主人**：看完会把「今天看了什么」发到 `OWNER_QQ_UMO`。

### 限制

- LV0 账号发评论 `-107`、发私信 `21016`，是 B 站限制，不是 bug；
- 没配视觉模型只能看字幕/热评/标题；
- 视频解析要 `ffmpeg` / `yt-dlp`，见 [03](03-插件说明.md#3-bilibili_ai_botb-站)。

## 8. QQ 空间

### 绑定

首次 `/qzone 帮助` 或 WebUI 里按提示扫码，Cookie 会存进插件数据目录。

### 发说说

- 定时：`trigger.publish_cron`（默认每天 20:00，±30 分钟抖动）；
- 手动：`/发说说 今天实验室又……`；
- 新闻短评：`/新闻说说`；
- 日常自拍（需配图模型）：`life_publish.enabled = true`。

### 评论 / 点赞

看好友动态后按 `comment_pipeline_enabled` 走「判断 → 推理 → 执行」三步，默认跳过签到类说说。

### 注意

空间风控严，别把频率调高；`comment_max_length` 默认 60 字。

---

## 9. 热搜 / 梗 / 已读不回

- **热搜**：直接发 `/微博热搜`、`/抖音热搜`……出图片；想每天定时推送，在配置里填 `push_time`。
- **梗百科**：`/梗 词`，本地查不到会联网；`gate_mode: llm` 表示由模型判断要不要查，省调用。
- **已读不回**：模型可以主动选择沉默；管理员和被点名的会话不受影响（`protected_admins` / `must_reply_umo`）。

## 10. 换人格 / 改说话风格

### 换默认人格

AstrBot → 人格 → 选一个 → 「设为默认」。等价于改：

```json
"agent_runner": { "config": { "persona": { "persona_id": "牧濑红莉牺" } } }
```

### 改人格内容

WebUI 里直接编辑保存即可，下一条消息生效。建议改完导出一份到 `personas\`，方便版本管理（**不要**把人名、地址、账号写进去）。

### 只改某个会话

AstrBot → 会话管理 → 选会话 → 指定人格，不影响全局默认。

### 调回复风格（不换人格）

- 分段回复：`platform_settings.segmented_reply`（默认开，按句号/问号切）；
- 回复引用/@：`reply_with_quote` / `reply_with_mention`；
- 流式：`streaming_response`（默认关）；
- 工具调用展示：`show_tool_use_status`。

## 11. 看日志

```powershell
# AstrBot 实时
Get-Content .\logs\astrbot.out.log -Tail 50 -Wait

# SnowLuma 实时（简版）
Get-Content .\logs\snowluma.out.log -Tail 50 -Wait

# SnowLuma 详细（DEBUG，排查首选）
Get-Content (Get-ChildItem C:\SnowLuma\logs -Filter 'snowluma-*.log' |
  Sort-Object LastWriteTime -Descending | Select-Object -First 1).FullName -Tail 80 -Wait

# 向量服务 / TTS
Get-Content .\logs\embedding.err.log -Tail 30
Get-Content .\logs\tts.err.log -Tail 30
```

**日志里有 API Key 吗？** AstrBot 默认不打印 Key；但插件报错可能带请求头。把日志发给别人前先搜一遍 `sk-`。

## 12. 备份

```powershell
$dst = "E:\backup\qqbot\$(Get-Date -Format yyyyMMdd)"
robocopy .\astrbot\data $dst\astrbot-data /E /XD temp logs attachments
robocopy .\deploy $dst\deploy /E
```

必须包含：`deploy\config.psd1`、`data\cmd_config.json`、`data\data_v4.db`、`data\config\`、`data\plugin_data\`、SnowLuma `config\`。

## 13. 资源占用

| 进程 | 常驻内存 | 说明 |
|---|---|---|
| AstrBot | 300~800 MB | 装了很多插件，首次加载慢 |
| SnowLuma | 150~300 MB | 含注入的 QQ hook |
| 向量服务 | 300~600 MB | 加载 bge 后常驻 |
| TTS | 1~4 GB | 视模型与后端（TensorRT / ONNX） |
| QQ | 300~800 MB | |

笔记本建议插电；电池模式下 Windows 可能 3 分钟就睡眠，主动消息会停。

## 14. 想加新插件

1. AstrBot → 插件市场 → 安装；
2. 依赖装不上时，手动：

   ```powershell
   $py = Join-Path (uv tool dir) 'astrbot\Scripts\python.exe'
   & $py -m pip install -r astrbot\data\plugins\<插件>\requirements.txt
   ```

3. 配置在 `data\config\<插件>_config.json`；
4. **别把插件的运行时数据提交到 Git**（`data\plugin_data` 已在 `.gitignore`）。

## 15. 一句话速查

| 想做什么 | 怎么做 |
|---|---|
| 启动 / 停止 | `start-all.ps1` / `stop-all.ps1` |
| 打开面板 | 双击 `打开管理页.bat` |
| 改密码 | 面板 → 头像 → 账户 |
| 换人格 | 面板 → 人格 → 设为默认 |
| 改主动消息频率 | `proactive_chat_config.json` → 重启 |
| 暂停主动消息 | `friend_settings.enable = false` |
| 关语音 | `ja_voice_config.json` → `enable: false` |
| 关自动收图 | `meme_manager_config.json` → `auto_collect.enabled = false` |
| 看 B 站今天看了啥 | `plugin_data\astrbot_plugin_bilibili_ai_bot\watch_log.json` |
| 机器人能发不能收 | 重启 QQ（SnowLuma 保持运行） |
| 全部重来 | `stop-all.ps1` → `verify.ps1` → `start-all.ps1` |
