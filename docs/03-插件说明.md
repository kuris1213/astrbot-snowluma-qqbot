# 03 · 插件说明

> 10 个插件都在 `resources\plugins\`（安装时复制到 `astrbot\data\plugins\`）。
> 每个插件的配置在 `astrbot\data\config\<插件名>_config.json`，数据在 `astrbot\data\plugin_data\<插件名>\`。
> 插件代码本身是第三方的，见 [THIRD_PARTY.md](../THIRD_PARTY.md)。

## 1. meme_manager（表情包管理器）

### 作用

把分类好的表情包注入提示词：模型输出 `&&分类键&&`，插件把标记换成图片发送。还支持自动收集群友发的图、图床同步、语义检索。

### 文件

```text
astrbot\data\plugins\astrbot_plugin_meme_manager\
astrbot\data\config\astrbot_plugin_meme_manager_config.json
astrbot\data\plugin_data\meme_manager\
├─ registry.json               # 已安装资源包
├─ selection_rules.json        # 默认选包规则
└─ packs\
   ├─ deepseek-girl-pack\      # 大肥鱼表情包（45 张）
   └─ local-9552ab28ba5fe56b\  # 牧濑红莉牺表情包（135 张，默认）
```

### 关键配置

| 段 | 键 | 说明 |
|---|---|---|
| `auto_collect` | `enabled` | 自动收集群友图片（默认开） |
| | `vision_provider_id` | 用哪个多模态模型识别图片，`deepseek/deepseek-flash` |
| | `sampling_probability` | 采样概率 50% |
| | `daily_recognition_limit` | 每天最多识别 100 张 |
| | `min_meme_confidence` | 0.85 才收 |
| `semantic` | `enabled` | 默认 `false`：走原生分类，不依赖向量模型 |
| `generation` | `emotion.probability` | 80% 概率判断要不要配图 |
| `storage` | `provider` | `cloudflare_r2` / `lsky` / `webdav` / `stardots`，默认全空，纯本地 |

### 命令

`/表情管理` 打开 WebUI（查看图库、添加、恢复默认包、导入导出）。

### 注意

- 自动收集会把群友的图存进 `plugin_data`，**属于他人内容**，公开仓库前不要提交。
- 表情包图片有版权，见 [NOTICE.md](../NOTICE.md)。
- 语义检索要开的话，先确保 `:8010` 在跑，再把 `semantic.enabled` 改 `true`。

## 2. proactive_chat（主动消息）

### 作用

在私聊/群聊冷场后主动开口，带独立管理端 `:4100`，能手动触发、看计划、改频率。

### 关键配置

| 键 | 默认 | 说明 |
|---|---|---|
| `friend_settings.enable` | `true` | 私聊主动消息总开关 |
| `friend_settings.session_list` | `["snowluma:FriendMessage:<主人QQ>"]` | **空数组 = 永不触发** |
| `auto_trigger_settings.auto_trigger_after_minutes` | 60 | 冷场多久后触发 |
| `schedule_settings.min/max_interval_minutes` | 30 / 120 | 两次之间的随机间隔 |
| `schedule_settings.quiet_hours` | `"23-10"` | 免打扰时段 |
| `schedule_settings.max_unanswered_times` | 4 | 连续几次没回就暂停（对方回一句即重置） |
| `tts_settings.enable_tts` | `true` | 未配 TTS provider 时退化为纯文本 |
| `web_admin.port` | 4100 | 管理端端口，无密码，只绑回环 |

### 管理端 API

```powershell
# 立刻触发一次（会真的发消息）
$umo = [uri]::EscapeDataString('snowluma:FriendMessage:<主人QQ>')
Invoke-WebRequest "http://127.0.0.1:4100/api/jobs/$umo/trigger" -Method Post `
  -Body '{}' -ContentType 'application/json' -UseBasicParsing
```

### 注意

- 电脑睡眠会错过 APScheduler 的定时任务。旧部署给 `core/task_scheduler.py` 打过 `misfire_grace_time = 86400` 的补丁；本仓库是上游原版，没带补丁。需要的话见 [06-排障](06-排障手册.md#2-主动消息不发)。
- `quiet_hours` 格式必须是 `"23-10"` 这种，写错等于不设免打扰。

## 3. bilibili_ai_bot（B 站）

### 作用

让 bot 有自己的 B 站账号：回评论、回私信、主动刷视频并点赞/收藏/关注/评论，把「今天看了什么」推送给主人。

### 关键配置

| 键 | 说明 |
|---|---|
| `SESSDATA` / `BILI_JCT` / `REFRESH_TOKEN` / `BUVID3` / `BUVID4` | B 站 Cookie，**模板里全是空**，扫码或手动填 |
| `DEDE_USER_ID` | 机器人 B 站 UID |
| `OWNER_MID` | 主人 B 站 UID |
| `OWNER_QQ_UMO` | 通知发到哪个 QQ 会话 |
| `LLM_PROVIDER_ID` | 默认 `deepseek/deepseek-chat`（长提示词下更稳） |
| `USE_ASTRBOT_PERSONA` | 跟随全局人格 |
| `ENABLE_REPLY` / `POLL_INTERVAL` | 评论回复，20 秒轮询 |
| `ENABLE_PRIVATE_MESSAGES` / `PRIVATE_MESSAGE_REPLY_SCOPE` | 私信回复范围（`owner` = 只回主人） |
| `ENABLE_PROACTIVE` | 主动看视频 |
| `PROACTIVE_LIKE/FAV/COMMENT/FOLLOW` + `*_MIN_SCORE` | 互动阈值 |
| `PROACTIVE_DAILY_LIMIT` / `AUTONOMOUS_PROACTIVE_DAILY_LIMIT` | 日上限（实际取较小值） |
| `SLEEP_START` / `SLEEP_END` | 睡眠时段（2~8 点不活动） |
| `BEHAVIOR_GLOBAL_MAX_PER_MINUTE` / `BEHAVIOR_GLOBAL_DAILY_LIMIT` | 行为预算，防刷 |

### 命令（管理员）

`/bili帮助`、`/bili登录`、`/bili状态`、`/bili主动`、`/bili停止`、`/bili刷新`、`/bili动态`、`/bili解析`、`/bili记忆`、`/bili周总结`、`/bili黑名单`……

### 依赖

- `ffmpeg` / `ffprobe` / `yt-dlp`（视频解析、切片）。装好后把目录填进 `deploy\config.psd1` 的 `ToolsBin`，或放进 `tools\bin`。
- 插件自带字体（`assets\fonts\NotoSansSC-VF.otf`，14 MB），出图用。

### 限制

- 新注册的 B 站账号是 LV0：发评论报 `-107 账号未转正`，发私信报 `21016 等级不够`，这不是程序问题。
- 未配视觉模型时只能靠字幕 + 热评 + 标题分析，不能截帧。
- 插件会自动刷新 Cookie；Cookie 失效会在日志里提示重新登录。

## 4. ja_voice（中文文字 + 日语语音）

### 作用

收到消息后，把回复**照常发文字**，同时把中文翻成日语、调本地 TTS 合成语音发出去。项目自带的轻量插件。

### 配置

```json
{
  "enable": true,
  "tts_base": "http://127.0.0.1:9882/v1",
  "model": "kurisu-v2proplus",
  "voice_profile": "default",
  "language": "ja",
  "probability": 1.0,
  "keep_text": true,
  "timeout": 120,
  "inject_voice_rule": true,
  "block_self_tts_commands": true
}
```

| 键 | 说明 |
|---|---|
| `enable` | 总开关；TTS 没起时建议先关 |
| `tts_base` | AnifLive-TTS 的 OpenAI 兼容地址 |
| `language` | `ja` = 先翻译成日语再合成；`zh` = 直接中文 |
| `probability` | 1.0 = 每条都发语音；调低可省时间 |
| `keep_text` | 同时发文字 |
| `inject_voice_rule` | 往提示词里注入「用口语短句」的规则 |

### 依赖

本地 TTS 服务 `:9882`，见 [05-模型与语音](05-模型与语音.md)。没装 TTS 时：

```powershell
# 先关掉，避免每条消息都超时
notepad astrbot\data\config\astrbot_plugin_ja_voice_config.json
# 把 "enable" 改成 false，重启 AstrBot
```

## 5. qzone_ultra（QQ 空间）

### 作用

用机器人账号发说说、看好友动态、评论、点赞；有独立守护进程 `:18999`，支持定时发说说、新闻短评、回评。

### 关键配置

| 段 | 键 | 说明 |
|---|---|---|
| `llm` | `post_provider_id` / `news_provider_id` / `comment_*` | 全用 `deepseek/deepseek-flash` |
| | `post_prompt` / `news_prompt` / `comment_prompt` / `reply_prompt` | 按角色口吻写死，可改 |
| `trigger` | `publish_cron` | 定时发说说（默认每天 20:00 + 30 分钟抖动） |
| `cookies_str` | | 空间 Cookie，空 = 首次在面板扫码绑定 |
| `admin_uins` | | 管理员 QQ（模板已替换成主人 QQ） |
| `daemon_port` / `auto_start_daemon` | | 守护进程端口与自启 |
| `native_video_publish` | | 原生视频发布 |

### 命令

`/qzone 帮助`、`/发说说`、`/看说说`、`/评说说`、`/赞说说`、`/回评`、`/查看访客`、`/绑定`、`/解绑`……

### 注意

- 首次使用需要在 WebUI 里扫码绑定空间 Cookie（`auto_bind_cookie: true`）。
- 空间风控比 QQ 更严，频率别调高；默认已经是低频率。
- 守护进程异常时先看 `plugin_data\astrbot_plugin_qzone_ultra\` 下的日志。

## 6. memewiki（梗百科）

### 作用

问「xxx 是什么梗」时查本地梗库，查不到回退 cnmeme.wiki；返回图片卡片。每天 8 点自动同步。

### 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `reply_mode` | `image` | 图片卡片 / 文本 |
| `auto_sync_enable` / `auto_sync_hour` | true / 8 | 每天同步 |
| `gate_mode` | `llm` | 用 LLM 判断要不要查梗（省调用） |
| `archive_enable` | true | 本地归档，90 天 |
| `sync_detail_limit` | 1000 | 同步条数 |

### 命令

`/梗 <词>`、`/梗档案`、`/网搜`、`/黑话`。

### 数据

`plugin_data\astrbot_plugin_memewiki\` + 插件自带 `data\memes.db`（16 MB 梗库，已随仓库提供）。

## 7. suanle_bushuo（算了不说）

### 作用

给模型一个「选择沉默」的工具，实现「已读不回」；同时支持拉黑、必回名单。

### 配置

| 键 | 说明 |
|---|---|
| `enable` | 总开关 |
| `silence_tool_enable` | 给模型 `silence` 工具 |
| `must_reply_umo` | 必回会话（模板已填主人 QQ），被点名一定回 |
| `protected_admins` | 管理员不受沉默影响 |
| `blocked_context_window` | 沉默后保留多少条上下文 |

### 命令

`/拉黑`、`/取消拉黑`、`/黑名单`。

## 8. hotsearch（全网热搜）

### 作用

聚合 30+ 站点热搜（抖音/小红书/知乎/微博/B 站/头条/豆瓣…），输出图片。

### 配置

- 各站点 API 走 `https://api.nycnm.cn/api/v2/*`（第三方聚合，稳定性不保证）。
- `push_time` 为空 = 不主动推送，只在命令触发时出图。

### 命令

`/微博热搜`、`/抖音热搜`、`/知乎热搜`、`/哔哩哔哩热搜`、`/百度热搜`、`/豆瓣热榜`…… 完整列表看 `/help_hotsearch`。

### 依赖

`aiohttp`（AstrBot 环境已有）。出图需要字体，插件自带。

## 9. mailer（发邮件）

### 作用

给 LLM 一个受控的发邮件工具；有域名/收件人白名单、附件大小限制。

### 配置

```json
"smtp": {
  "host": "", "port": 465, "use_tls": true,
  "username": "", "password": "", "from_email": ""
}
```

模板里 **SMTP 全空**，不填就发不出去（工具会报错，不会静默）。

### 命令

`/mail_config_check`（检查配置）、`/mail_test`（发测试邮件）。

### 安全建议

- 用独立邮箱 + 应用专用密码，不要用主邮箱密码。
- 把 `security.allowed_domains` 填上你允许的收件域名，避免被提示词注入拿去发垃圾邮件。

## 10. zhen_deepseek_web（DeepSeek 联网搜索）

### 作用

给模型 `deepseek_web_search` / `deepseek_web_fetch` 工具，用 DeepSeek 官方联网能力搜索、抓网页、出摘要图。

### 配置

```json
{
  "api_key": "",
  "base_url": "https://api.deepseek.com",
  "search_count": 8,
  "fetch_output_mode": "image",
  "max_content_chars": 8000
}
```

- `api_key` 为空时工具不可用；填上 DeepSeek Key 即可（可以和 `cmd_config.json` 里的是同一个）。
- 不需要额外 pip 依赖，`_vendor` 里自带 requests/urllib3。

### 命令

`/dsweb 搜索 <词>`、`/dsweb 抓取 <url>`。

## 附：插件被禁用/卸载后

| 现象 | 处理 |
|---|---|
| 插件升级后配置字段变了 | WebUI → 插件 → 配置，会按 `_conf_schema.json` 自动补默认值 |
| 插件报缺依赖 | WebUI → 插件 → 安装依赖；或 `uv pip install --python <astrbot python> -r requirements.txt` |
| 想彻底移除 | 删 `data\plugins\<名>` + `data\config\<名>_config.json` + `data\plugin_data\<名>` |
| 残留配置 | 仓库只带 10 个在用的插件，`astrbot_plugin_genshinimpact` / `stealer` / `what_to_eat` 的残留配置**没有**包含 |
