# 01 · 从零部署

> 目标：一台**全新**的 Windows 10/11 x64 电脑，从没装过 Python / Node / AstrBot / SnowLuma，按本文能跑起同一套机器人。
> 全程约 30~60 分钟，其中大部分是下载时间。

---

## 0. 先确认这些

### 0.1 硬件与系统

| 项 | 最低 | 建议 |
|---|---|---|
| 系统 | Windows 10 1909 x64 | Windows 11 23H2+ |
| 内存 | 8 GB | 16 GB（本地向量 + TTS 更稳） |
| 磁盘 | 5 GB 空闲 | 20 GB（含 7 GB 语音模型 + 依赖） |
| 网络 | 能访问 PyPI / GitHub / DeepSeek | 国内建议给 `uv` / pip 配镜像 |
| 显卡 | 无要求 | 只有本地日语语音需要 NVIDIA 显卡 + TensorRT；其它功能纯 CPU 可跑 |

### 0.2 账号

| 账号 | 用途 | 注意 |
|---|---|---|
| QQ 小号（机器人） | 登录 QQ NT，被 SnowLuma 接管 | 不要用主号，有封号风险 |
| 你的 QQ（主人） | 收通知、执行 `/bili主动` 等管理员命令 | 需要和机器人是好友 |
| DeepSeek | 对话模型 | 没有也能跑，只是不会回话 |
| B 站小号 | 可选，B 站插件 | 新号 LV0 发评论/私信会被平台拦 |

### 0.3 先装好 QQ NT

从 <https://im.qq.com/> 下载 **QQ NT 版**（不是旧版 QQ），安装后用机器人小号登录一次，确认能正常收发消息，再退出。

> 记下 `QQ.exe` 的实际路径，安装脚本会问；常见是 `C:\Program Files\Tencent\QQNT\QQ.exe`。

## 1. 获取代码

```powershell
git clone https://github.com/<你的账号>/<仓库名>.git D:\QQBot
cd D:\QQBot
```

没有 Git 就下载 ZIP 解压到 `D:\QQBot`。

> **路径建议**：纯英文、无空格，例如 `D:\QQBot`。中文路径会让 `startup-hidden.vbs`（开机自启）和部分插件的子进程出问题。

## 2. 安装 SnowLuma（第三方，必须手动）

SnowLuma 是闭源分发 + 专有组件的协议端，**不在本仓库里**，也不能由脚本替你下载（授权原因）。

### 2.1 下载

从 SnowLuma 官方发布渠道获取 **Windows x64 完整版**（2.2.x），文件名类似 `SnowLuma-2.2.1-win32-x64.zip`，约 130 MB。

官方渠道以 SnowLuma 作者公布为准（QQ 群 / GitHub Releases / 官网）。**不要**从来路不明的网盘拿，协议端会注入 QQ 进程，被篡改等于把账号交出去。

### 2.2 解压

解压到 **仓库之外** 的目录，推荐 `C:\SnowLuma`，解压后应看到：

```text
C:\SnowLuma\
├─ node.exe                 # 自带 Node 24
├─ index.mjs
├─ launcher.bat
├─ native\                  # hook 用的 dll / node 模块
├─ client\                  # WebUI 静态资源
├─ config\                  # 配置（install.ps1 会写这里）
├─ data\
└─ logs\
```

### 2.3 为什么不能放仓库里

- SnowLuma 需要给 QQ 进程注入 hook。放在被同步盘、沙箱、或带「低完整性标签」的目录里，注入会失败（日志报 `Node integrity: Low`）。
- 它的 EULA 不允许把专有组件并入第三方安装包/镜像再分发，放进 Git 历史属于再分发。

### 2.4 首次启动

可以手动双击 `launcher.bat` 先跑一次，确认能打开 <http://127.0.0.1:5099>；也可以等第 4 步由脚本启动。

首次启动会要求同意 EULA/隐私协议；WebUI 初始密码只打印一次。**本仓库的 `start-snowluma.ps1` 会通过环境变量预设一个初始密码**（见 `deploy\config.psd1` 的 `SnowLumaWebUIPassword`），登录后请立刻改掉。

> 如果你先跑了 `install.ps1` 才下载 SnowLuma，装好后**再跑一次 `install.ps1`**（参数可以全部回车复用），它会把
> `templates\snowluma\*.json` 渲染进 `C:\SnowLuma\config\`。也可以手动复制模板并把 `REPLACE_WITH_RANDOM_ONEBOT_TOKEN`
> 换成 `deploy\config.psd1` 里的 `OneBotToken`。

## 3. 初始化 AstrBot 与配置

### 3.1 一键脚本（推荐）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\install.ps1
```

交互会问：

| 问题 | 填什么 |
|---|---|
| 机器人 QQ 号 | 小号 QQ |
| 主人 QQ 号 | 你自己的 QQ |
| AstrBot 工作目录 | 直接回车 = 仓库下的 `astrbot` |
| SnowLuma 解压目录 | `C:\SnowLuma` |
| QQ.exe 路径 | 自动探测，错了就手填 |
| DeepSeek API Key | `sk-...`，可留空 |
| 安装本地向量依赖？ | 需要知识库语义检索就 Y（约 1~2 GB） |

> **关于 DeepSeek Key**：仓库和作者都不提供 Key。它是**部署者自己**在
> <https://platform.deepseek.com/api_keys> 注册后拿到的账号凭据，调用费用记在你自己的账户。
> 安装时填的 Key 只会写进本机的 `deploy\config.psd1` 与 `astrbot\data\cmd_config.json`（都被 `.gitignore` 排除），
> 同时会生成 `logs\API-KEY-README.txt` 说明。留空也能装完，只是机器人不会回话；
> 之后到 <http://127.0.0.1:6185> → 服务商 → `deepseek` 补填即可。

它会做这些事：

1. 安装 `uv`（如果没有），再 `uv tool install astrbot==4.29.3 --python 3.12`；
2. 建 `astrbot\.astrbot` 与 `astrbot\data\{config,plugins,plugin_data,knowledge_base,...}`；
3. 把 `resources\plugins`、`resources\meme-packs`、`resources\knowledge_base` 铺进去；
4. 生成随机 OneBot 令牌，把 `templates\` 渲染成真实配置；
5. 写 `deploy\config.psd1`、`startup-hidden.vbs`、`打开管理页.bat`；
6. 可选创建 `.venv-embedding` 并装 torch CPU + transformers。

最后会打印 SnowLuma 初始密码，**记下来**。

### 3.2 非交互式

```powershell
.\deploy\install.ps1 -Yes `
  -BotQQ 123456789 -AdminQQ 100000001 `
  -DeepSeekKey sk-xxxxxxxx `
  -SnowLumaHome C:\SnowLuma `
  -SkipEmbedding
```

`-SkipEmbedding` 表示先不装向量依赖，之后可重跑 `install.ps1` 补上。

### 3.3 手动等价步骤（不想用脚本时）

```powershell
# 1) 安装 uv
winget install -e --id astral-sh.uv
# 或：powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# 2) 安装 AstrBot
uv tool install astrbot==4.29.3 --python 3.12

# 3) 建工作目录
cd D:\QQBot
New-Item -ItemType Directory -Force astrbot\data\config, astrbot\data\plugins, `
  astrbot\data\plugin_data, astrbot\data\knowledge_base, logs
New-Item -ItemType File -Force astrbot\.astrbot

# 4) 铺资源
Copy-Item resources\plugins\* astrbot\data\plugins -Recurse -Force
Copy-Item resources\meme-packs\* astrbot\data\plugin_data\meme_manager -Recurse -Force
Copy-Item resources\knowledge_base\* astrbot\data\knowledge_base -Recurse -Force

# 5) 渲染配置（把占位符换成你的值）
$uvpy = Join-Path (uv tool dir) 'astrbot\Scripts\python.exe'
& $uvpy deploy\tools\render_config.py --repo . --token <32位随机令牌> `
  --bot-qq <机器人QQ> --admin-qq <主人QQ> --deepseek-key <sk-...> --snowluma-home C:\SnowLuma
```

## 4. 配置 OneBot 连接（脚本已自动做，这里是原理）

两端必须**完全一致**：

| 位置 | 字段 |
|---|---|
| `astrbot\data\cmd_config.json` | `platform[0].ws_reverse_token` |
| `C:\SnowLuma\config\onebot.json` | `networks.wsClients[0].accessToken` |
| `C:\SnowLuma\config\onebot_<机器人QQ>.json` | 同上 |

连接方向：**SnowLuma 主动连 AstrBot**，地址 `ws://127.0.0.1:6199/ws`。

账号级配置（`onebot_<QQ>.json`）会覆盖全局 `onebot.json`。**只让机器人的账号启用 `wsClients`**；如果主人的号也开了桥接，会出现两个连接、重复回复。

如果登录后 SnowLuma 自动生成了 `onebot_<QQ>.json` 并覆盖了令牌，去 SnowLuma WebUI 的「网络」页把 `astrbot` 这条的 `accessToken` 改回 `deploy\config.psd1` 里的 `OneBotToken`，或反过来改 AstrBot。

## 5. 启动与验证

### 5.1 启动

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\start-all.ps1
```

顺序：向量服务 → SnowLuma → AstrBot →（可选）TTS → QQ。

**为什么 QQ 必须最后起**：SnowLuma 的 hook 要在 QQ 进程启动时注入。先开 QQ、后开 SnowLuma，会出现「机器人能发消息、但完全收不到消息」，而且重启 SnowLuma 修不好（只会复用坏掉的 hook），必须重启 QQ。

### 5.2 看日志确认

```powershell
# AstrBot 启动完成
Select-String .\logs\astrbot.out.log -Pattern 'Dashboard|Initial password' | Select-Object -Last 5

# SnowLuma 注入 + 连上 AstrBot
Select-String .\logs\snowluma.out.log -Pattern '\[Hook\] login detected|WS-Client.*connected' | Select-Object -Last 10
```

正常应有：

```text
[Hook] login detected: UIN=<机器人QQ>
[OneBot] session started
[OneBot.WS-Client] [astrbot] connected
```

更详细的 SnowLuma 日志在 `C:\SnowLuma\logs\snowluma-YYYY-MM-DD.log`。

### 5.3 自检脚本

```powershell
.\deploy\verify.ps1
```

会检查：`config.psd1`、AstrBot 命令、`.astrbot`、`cmd_config.json` 占位符残留、OneBot 令牌两侧一致、SnowLuma 目录、插件数、表情包、向量模型、TTS 模型、端口。

### 5.4 端到端测试

1. 用你的 QQ 私聊机器人小号；
2. 发 `/help` → 应返回命令列表；
3. 发「在吗」→ 应调用 DeepSeek 回复；
4. 发一句带情绪的话 → 可能配表情包；
5. 打开 <http://127.0.0.1:6185> → 「平台」里应看到 `snowluma` 在线。

## 6. 首次登录 AstrBot

1. 打开 <http://127.0.0.1:6185>；
2. 用户名 `astrbot`，密码从日志里找：

   ```powershell
   Select-String .\logs\astrbot.out.log -Pattern 'Initial password'
   ```

3. 登录后**立刻改密码**（右上角头像 → 账户）；
4. 到「服务商」页确认 `deepseek` 的 Key 已填；没填就点编辑填上；
5. 到「人格」页确认默认人格已导入（见下一节）。

### 6.1 导入人格

人格正文在 `personas\牧濑红莉牺.txt`。两种方式：

- **推荐**：WebUI → 人格 → 新建 → 名称填 `牧濑红莉牺` → 把文本粘进系统提示词 → 保存 → 设为默认。
- 或者用 SQLite 直接写 `astrbot\data\data_v4.db` 的 `personas` 表（先备份）。

导入后在 `cmd_config.json` 里确认：

```json
"agent_runner": { "config": { "persona": { "persona_id": "牧濑红莉牺" } } }
```

## 7. 开机自启（可选）

`install.ps1` 已经生成 `startup-hidden.vbs`（纯 ASCII、无 BOM）。注册表方式：

```powershell
New-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -Name 'AstrBotQQBot' `
  -Value 'wscript.exe //B "D:\QQBot\startup-hidden.vbs"' -PropertyType String -Force
```

关闭：

```powershell
Remove-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -Name 'AstrBotQQBot'
```

或者用「任务计划程序」建一个「登录时」触发的任务，程序填 `wscript.exe`，参数 `//B "D:\QQBot\startup-hidden.vbs"`，勾选「不管用户是否登录都运行」可按需。

> 自启只拉起进程；QQ 需要保持登录（QQ 记住会话时会自动登录，否则要扫码）。
> 笔记本用电池时 Windows 可能 3 分钟就睡眠，导致定时任务错过，见 [06-排障手册](06-排障手册.md)。

## 8. 备份与迁移

### 8.1 必须备份

```text
deploy\config.psd1                       # 你的 Key / 令牌 / 路径
astrbot\data\cmd_config.json             # 主配置
astrbot\data\data_v4.db                  # 人格 / 会话 / 消息
astrbot\data\config\                     # 插件配置（含 B 站 Cookie）
astrbot\data\plugin_data\                # 表情包、B 站账本、主动消息状态
C:\SnowLuma\config\                      # 协议端配置
personas\                                # 人格文本
```

这些都是小文件。写个 `robocopy` 到网盘/移动硬盘即可，**不要**提交到 Git。

### 8.2 迁移到新机器

1. 按本文装好 QQ、SnowLuma、uv、AstrBot；
2. 把上面的备份覆盖到对应位置（`deploy\config.psd1` 里的绝对路径要改）；
3. 跑 `.\deploy\verify.ps1`；
4. `.\deploy\start-all.ps1`，先 SnowLuma 后 QQ；
5. 用机器人小号扫码登录。

```powershell
.\deploy\stop-all.ps1 -IncludeQQ

```
