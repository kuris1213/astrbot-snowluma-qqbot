# 07 · 安全与脱敏

> 目标：仓库可以公开，而你的 API Key、QQ 号、Cookie、聊天记录、面板密码一个都不在里面。

**仓库不提供任何可用的 DeepSeek API Key。** 每个部署者用自己的 DeepSeek 账号 Key，费用记在自己账户；
`install.ps1` 与 `start-astrbot.ps1` 会把这条提醒写到控制台和 `logs\API-KEY-README.txt`。

---

## 1. 已脱敏的内容

原始部署里的以下内容**全部没有进仓库**：

| 类别 | 原值示例 | 处理 |
|---|---|---|
| DeepSeek API Key | `sk-2f3c...` | 换成 `sk-REPLACE_WITH_YOUR_DEEPSEEK_KEY` |
| OneBot 令牌 | 32 位十六进制 | 换成 `REPLACE_WITH_RANDOM_ONEBOT_TOKEN`，安装时随机生成 |
| AstrBot 面板密码哈希 / JWT | `pbkdf2_sha256$...` / 64 位 hex | 置空，由 AstrBot 首次启动重新生成 |
| SnowLuma 面板密码哈希 | `passwordHash` / `passwordSalt` | 不打包；安装时用 `SnowLumaWebUIPassword` 重新初始化 |
| B 站 Cookie | `SESSDATA` / `BILI_JCT` / `REFRESH_TOKEN` / `BUVID3/4` | 全部置空 |
| 机器人 / 主人 QQ、B 站 UID | 具体数字 | 换成 `YOUR_QQ_NUMBER`，安装时填 |
| 聊天记录 | `data_v4.db`（42 MB） | 不打包，只保留人格文本 |
| 面板账号密码 | 明文/哈希 | 不打包，首次启动生成 |
| 本机路径 | `D:\astrabot`、`C:\Users\<用户名>\...` | 脚本全部改为相对仓库 + `config.psd1` |
| 个人文档 | `密码.doc` | 不打包 |
| 运行日志 | 含 IP、QQ、请求头 | 不打包（`.gitignore`） |

另外这些**没有**进仓库：`data_v4.db`、`plugin_data` 下的 B 站账本 / 主动消息状态 / 空间 Cookie、`logs\`、`.venv-embedding`、SnowLuma 的 `data\`（含会话缓存）。

## 2. 占位符机制

`templates\` 里只有四种占位符：

```text
sk-REPLACE_WITH_YOUR_DEEPSEEK_KEY
YOUR_QQ_NUMBER
snowluma:FriendMessage:YOUR_QQ_NUMBER
REPLACE_WITH_RANDOM_ONEBOT_TOKEN
```

`install.ps1` → `render_config.py` 用 `deploy\config.psd1` 的值替换，写到运行时文件。所以：

- **模板可以公开**：没有任何秘密；
- **运行时文件不能公开**：已被 `.gitignore` 排除。

```powershell
git check-ignore -v deploy\config.psd1 astrbot\data\cmd_config.json
# 应输出匹配的规则行
```

## 4. 部署后自检

```powershell
# 1) 运行时文件只在你自己机器上
Test-Path deploy\config.psd1, astrbot\data\cmd_config.json

# 2) 配置里确实有你的 Key / 令牌（不要打印完整值）
Select-String deploy\config.psd1 -Pattern 'DeepSeekKey|OneBotToken'

# 3) 面板/协议端只监听回环
Get-NetTCPConnection -State Listen -LocalPort 6185,5099,6199 |
  Select-Object LocalPort, LocalAddress
```

如果要把仓库目录借给别人、或把整个文件夹拷到移动硬盘：

- 先排除 `deploy\config.psd1`、`astrbot\data\`、`logs\`、`models\tts\`；
- 或者直接重新下载一份仓库，不要带运行数据。

## 5. 密钥权限建议

| 密钥 | 权限 | 备注 |
|---|---|---|
| DeepSeek Key | 只用来调 API，不绑定支付方式以外的权限 | 在控制台可随时吊销 |
| B 站 Cookie | 小号专用 | 泄露等于账号被接管 |
| QQ 密码 | 机器人小号，独立密码 | 不要和主号相同 |
| OneBot 令牌 | 只在本机回环使用 | 泄露风险低，但仍不要公开 |
| SMTP | 应用专用密码 | 不要用主邮箱密码 |

- 面板全部只绑 `127.0.0.1`；**不要**用 frp/ngrok 把 6185/5099 暴露到公网。
- 如果一定要远程访问，用 WireGuard/Tailscale 组网，而不是端口映射。
- Windows 上给仓库目录加 ACL：只有你的账户可读写（`icacls`），避免同机其他用户读到 `config.psd1`。

## 6. 如果密钥泄露了

按「先止血」：

1. **立刻吊销**：
   - DeepSeek：控制台删除 Key，重新生成；
   - B 站：退出所有设备 / 改密码，重新登录；
   - SMTP：改应用密码；
   - SnowLuma / AstrBot：改面板密码；
2. **换令牌**：`deploy\config.psd1` 里 `OneBotToken` 换新的，重跑 `install.ps1 -Force`，重启两端；
3. 检查本机其他位置（截图、聊天记录、备份压缩包）是否也带了旧 Key，一并删除。

## 7. 数据与隐私边界

这套机器人会处理：

- 你和机器人的私聊（`data_v4.db`、SnowLuma `data\<QQ>\messages.db`）；
- 群聊消息（AstrBot 会话库、`proactive_chat` 状态）；
- B 站/QQ 空间的账号行为（`plugin_data`）；
- 自动收集的群友图片（`plugin_data\meme_manager`）。

建议：

1. **定期清理**：`data_v4.db` 会持续增长，AstrBot → 数据 → 清理会话；
2. **不要把** `data_v4.db`、`plugin_data`、`logs` 发给别人；
3. 群友图片属于他人内容，公开仓库前必须删 `plugin_data\meme_manager\packs` 里自动收集的部分；
4. 人格提示词里不要写真实个人信息；
5. 机器人回复里如果出现手机号/地址，属于模型幻觉，及时在人格里加约束。
