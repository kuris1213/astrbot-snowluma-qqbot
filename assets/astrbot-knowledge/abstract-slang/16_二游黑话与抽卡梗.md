二游（二次元手游）有一套自己的黑话，从抽卡到养成、从氪金到日常，几乎每个环节都有专用词。本篇按使用场景整理 2025—2026 年仍在高频使用的说法，标注含义与圈层。

## 抽卡基础

**卡池**：可以抽角色的池子，分限定池与常驻池。**限定**：只在特定时间开放的角色，过期要等复刻。**复刻**：老角色重新开池。

**单抽 / 十连**：一次抽 1 次或 10 次，十连通常有保底折扣。**垫**：为了凑保底或攒概率，先在别的池子里抽。

**保底**：抽到一定次数必出高稀有度，分**小保底**（第一次必出但可能歪）与**大保底**（歪了之后必出当期）。**歪**：出了高稀有度但不是当期角色，最常见的破防来源。

**井 / 天井**：抽满固定次数可以直接兑换当期角色，源自《碧蓝幻想》的 300 抽天井，现在泛指"硬保底兑换"。**一井**就是抽满一次保底所需的量。

## 欧非与玄学

**欧皇 / 非酋**：运气好 / 运气差的人。**海豹**：晒出货的人（"豹跳"指突然晒卡）。**沉船**：抽了很多却没出。**梭哈**：把资源一次性全抽掉。

**仓检**：怀疑系统检测你的仓库，故意不给你缺的角色。**读心**：想要什么偏不出什么。两者都是玩家调侃，没有实证。

**玄学**：垫刀、换时间、换地点、洗澡后抽之类的迷信操作。

## 氪金与资源

**648 / 328**：充值档位，648 元是最高档，常被当作"一单"的代称。**首充双倍**：首次充值送等额货币。

**月卡 / 大月卡**：小额订阅与通行证（战令、纪行）。**白嫖 / 零氪 / 微氪 / 重氪**：按付费程度分类。**氪佬**：氪金多的人。**仓鼠 / 屯屯鼠**：囤资源不抽的人。

## 养成与强度

**毕业**：角色练到够用或满配。**满命 / 满潜**：抽满重复角色解锁全部命座/潜能。**精二 / 专三**：技能与精英化等级拉满。

**人权卡**：没有就很难玩的角色。**T0 / 幻神**：强度最高的档位。**超模 / 数值怪**：强度超出平衡。**数值膨胀**：新角色越来越强。**退环境**：老角色被新版本淘汰。

**强度党 / XP 党**：按强度抽卡 / 按喜好抽卡。**抄作业**：照抄别人的配队与打法。**凹**：反复尝试刷分。**逃课**：用取巧方式跳过机制。

**长草期**：版本内容玩完、无事可做的阶段。**开荒**：新号或新版本初期推进度。

## 日常与运营

**清体力 / 树脂**：消耗每日体力。**周本 / 深渊**：周期性高难内容（各游戏叫法不同，如"混沌回忆""虚构叙事"）。**前瞻直播**：版本预告直播，通常发放**兑换码**。**补偿**：出事故后官方发的道歉奖励。**炸服 / 回档**：服务器崩溃、数据回滚。**土豆服务器**：嘲讽服务器差。**内鬼 / 舅舅党**：提前爆料的人。

## 账号相关

**初始号 / 自抽号 / 成品号**：不同来源的账号。**号贩子**：倒卖账号的人。**封号 / 私服**：违规与灰色地带，不建议碰。
